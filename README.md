## 📖 Overview

This is the source code for my personal developer portfolio — a fast, single-page site built to showcase my transition from 12 years of native Android engineering into modern fullstack web development. It's built as a single-file production bundle (HTML/CSS/JS inlined) for maximum portability and near-instant load times.

## ✨ Features

- ⚡ **Blazing fast** — Vite 7 build pipeline, bundled into a single deployable HTML file via `vite-plugin-singlefile`
- 🎨 **Modern styling** — Tailwind CSS 4 with `tailwind-merge` for clean, conflict-free utility composition
- ⚛️ **React 19** — latest concurrent features, functional components throughout
- 🔒 **Type-safe** — fully written in TypeScript
- 📱 **Responsive** — mobile-first layout across all breakpoints
- 🧩 **Zero backend required** — fully static, deployable anywhere

## 🛠️ Tech Stack

| Layer | Technology |
|---|---|
| UI Library | React 19 |
| Build Tool | Vite 7 |
| Language | TypeScript 5.9 |
| Styling | Tailwind CSS 4 |
| Utilities | clsx, tailwind-merge |
| Bundling | vite-plugin-singlefile |

## 🚀 Getting Started

### Prerequisites

- Node.js 18+ and npm

### Installation

```bash
# Clone the repository
git clone https://github.com/Dev-moe-kyawaung/moekyawaung-developer-portfolio-56.git
cd moekyawaung-developer-portfolio-56

# Install dependencies
npm install
```

### Development

```bash
npm run dev
```

Visit `http://localhost:5173` to view the app locally with hot module reloading.

### Production Build

```bash
npm run build
```

Outputs a single self-contained HTML file to `dist/`.

### Preview Production Build

```bash
npm run preview
```
