# Security Policy

## Supported Versions

This is a personal portfolio project maintained on a rolling basis. Only the
latest version on the `main` branch is supported with security updates.

| Version | Supported |
|---------|-----------|
| `main` (latest) | ✅ |
| Older commits/tags | ❌ |

## Reporting a Vulnerability

If you discover a security vulnerability in this repository (e.g. a
dependency with a known CVE, exposed secrets, or an XSS vector in the built
site), please **do not** open a public GitHub issue.

Instead, report it privately:

1. Open a [GitHub Security Advisory](https://github.com/Dev-moe-kyawaung/moekyawaung-developer-portfolio-56/security/advisories/new) for this repository, **or**
2. Contact the maintainer directly via GitHub: [@Dev-moe-kyawaung](https://github.com/Dev-moe-kyawaung)

Please include:
- A description of the vulnerability and its potential impact
- Steps to reproduce (or a proof of concept, if applicable)
- Any suggested remediation, if known

## Response Expectations

- You will receive an acknowledgment within **3–5 business days**.
- A fix or mitigation will be prioritized based on severity.
- Credit will be given in release notes if you wish (or you may remain anonymous).

## Scope

This policy covers the source code and build configuration in this repository.
It does not cover third-party services (e.g. the hosting provider) unless the
vulnerability originates from this project's own code or configuration.
